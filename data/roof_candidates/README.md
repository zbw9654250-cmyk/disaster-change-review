# Ebenezer 屋面候选输入

这三份 GeoJSON 均源自 Kucharczyk、Nesbit 和 Hugenholtz 公开的 `Polygons.zip` 中的 `s_ebenezer` 图层。保留对象类别和原类别数组下标，转为 WGS84 经纬度。分别有 178 个四地区专用候选、111 个两地区单类候选、103 个两地区双类候选。示例在相同测区运行等预算融合，期望导出 178 个对象。屋面候选使用 CC BY 4.0。[作者数据](https://zenodo.org/records/20581719) · [原论文](https://doi.org/10.3390/rs17203456) · [模块](../../modules/roof_candidates/README.md)
